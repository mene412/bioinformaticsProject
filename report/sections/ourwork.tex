We implement in Python the PAM and CLARANS algorithms, using both jaccard and bray-curtis distances. We tested CLARANS with different size of the random subset, resulting with different datasets.

Then we evaluate the clusterings. Using the labels of the sample derived from the dataset, we find a majority label for using the evaluation metrics, computing macro- and micro-averaging.
